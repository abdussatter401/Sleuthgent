READING THE RECORD

Evidence, inference, and non-claims

This viewer keeps recorded relationships separate from reconstruction heuristics. Every displayed activity can be traced back to its source locator.

01

Normalize sources

Android messages use timestamp and sequence ordering. Provider transcripts use sequence ordering.

02

Join stable IDs first

Message IDs join Android records to manifest turns. Call IDs pair tool calls with outputs.

03

Link matching content

Transcript prompts link to Android messages using whitespace-normalized exact text.

04

Group turns cautiously

Actions after a user message are assigned to it until the next user message. This is positional inference.

05

Report explicit approvals

Approval is shown only when a user-confirmation status exists in a tool output.

What the viewer does not claim

  • Assistant statements do not prove external effects.
  • Unlinked sessions are not necessarily unrelated.
  • Missing approvals do not prove no prompt appeared.
  • Android and provider session IDs are separate namespaces.
